# 3D printing

Printable versions of the "open source everything" design.
Each has its own folder with its files and print instructions.

- [Keychain](keychain/): in two colors, with light letters on a dark base or dark letters on a light base.
- [Wall sign](wall-sign/): the keychain design scaled up to fill a 256 mm build plate, with keyholes in the back to hang it on two nails.
